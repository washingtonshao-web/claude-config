# Documents

## Route
| Request | Build with |
|---|---|

## Structure (every route)
- Title, then a one-paragraph summary that states the conclusion and the key numbers behind it, if there are any (a shaded box is fine in Word).
- Numbered sections; each data claim sits near its chart or table.
- Sources at the end, numbered, matching the in-text markers.
- Restraint (SKILL.md): no "generated by", no version stamps, no filler headings.

## Word and PDF page and type
- A4, margins 2.2 cm; Microsoft YaHei UI for Chinese and Latin text (Segoe UI acceptable for Latin); body 10.5–11pt, line spacing 1.5; headings bold. Never SimSun (Word's default East Asian font): set it explicitly in the styles.
- Heading 1 16pt with a thin falcon-copper `#b4531f` rule under it; Heading 2 13pt; Heading 3 11pt bold. No more than 3 levels.
- Header: document title in 9pt grey. Footer: page number and date.
- Colors from `python "C:\Users\Administrator\.claude\skills\design\scripts\tokens.py" --style editorial`.

## Tables and figures
- Tables: header row bold with a 1pt ink rule under it, 0.5pt light rules between rows, no vertical lines, numbers right-aligned with thousands separators.
- Figures: matplotlib per `charts.md` at dpi 200, full text width. Numbered caption "图 1 …" stating the conclusion, then the source line in 9pt grey.

## Check
Convert to PDF and review the page images with the `review.md` scorecard. The usual failures are widows, tables split across pages, figure/caption separation, and SimSun creeping in through the East Asian font setting.
