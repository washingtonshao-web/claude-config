# Words

Read before writing any prose, caption, slide text or narration I will read or hear. The test: **would I say this sentence out loud to a colleague?** If not, rewrite it.

- **Fit the occasion first.** Internal talk / 讲课: a spoken story, first person plural, one idea per screen, a primer before jargon. Report: answer first, sections by question. Tool: labels and help text only. A style reference ("像券商报告") sets polish, not genre.
- **No report machine.** No tally sentences ("6 条倾向发生，4 条不发生"), no talk about the document ("判断按照…写", "本页"), no as-of or source note on every item (one as-of per page; sources in a drawer, footnote or method page), no internal labels (J1, Exhibit), no hedge repeated on every item.
- **Sentences.** Say Y instead of "不是 X，而是 Y"; no 首先/其次/综上/值得注意的是; no 赋能/闭环/抓手/底层逻辑/里程碑式; no aphorism endings; no colon labels on every line; dashes rarely; name who said it. English: no delve/pivotal/landscape/leverage, no "not just X but Y".
- **For the ear.** ≤25 characters per spoken clause, one number per sentence, round numbers unless the exact value matters. The voice is picked by listening to 2–4 samples (animation-making), not from a transcript.

Full checklist, measurement script (`ai_tells.py`) and rewrite procedure: the **de-ai** skill. Use it when I ask (去AI味 / humanize) or when a review flags the words.
